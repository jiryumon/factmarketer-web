## 1. 회사 성격
- 정보통신 서비스 업체 + 자체 솔루션 개발사. "기업의 통신시스템을 일괄 처리해 드리는 정보통신 전문 기업" [회사 p3]
- 사업 4축: 콜센터 솔루션 개발, 시스템 통합(SI), 시스템 유지보수, 기업 통신(회선·전화) [회사 p6~p10]
- 자체 기술 근거: 부설연구소, 특허 등록, 상표 등록("티링크레코딩", "티링크미니") [회사 p4, p5, p12]
- 판매 방식: 월 구독 + 설정비 + 설치·연동 (무료 상담 → 맞춤 설치·연동 → 리포트 자동 생성) [제안 s10]

## 3. 기술적 차별점 (근거 강도 순)

### ① 3채널 통합 녹취 → 고객별 하나의 이력 ★핵심
- 사무실 인터넷전화 + 직원 휴대폰 + PC 소프트폰 → 하나의 서버, 고객별 하나의 이력. 외근 통화까지 리포트 분석에 포함 [제안 s3]
- 비교 대상으로 제시된 "일반적인 녹취 방식": 사무실 전화는 녹취기, 휴대폰은 직원 폰에 따로 남음 [제안 s3]
- 휴대폰 녹음은 앱이 자동 전송, 실패·누락분은 재전송 기능 [모바일 s24, s25]
- 회선 호환: LG·SK·KT [제안 s3], [가이드 미션2]
- ⚠ 주의: PC폰의 통화 녹음은 "삼성 070 계정에서만 사용 가능" [PC폰 p15, p16]

### ② 통화 밖의 영업 활동까지 수집 (자료에서 덜 강조된 강점)
- 문자(SMS/MMS) 수신·발신 내역도 서버로 전송·조회 [모바일 s10~s12, s28]
- 대면 녹취: 현장 대화를 앱으로 녹음 → 제목 입력 → 업로드 [모바일 s26, s27]
- → "현장 미팅까지 기록"이라는 메시지가 가능 (과제의 '현장'과 연결 가능)

### ③ 통화 직후 AI 자동 기록
- STT(음성→글자), 고객/상담원 발화 구분, AI 한줄요약, 키워드 추출 [모바일 s7], [CRM p15]
- 한줄요약으로 통화 검색 [CRM p14]
- 키워드 통계를 트리맵으로 시각화 [모바일 s17]
- 통화 기록에서 바로 상담 등록 → CRM 이력으로 연결 [CRM p15]

### ④ 종합리포트: 녹취를 경영·인사·교육 보고서로 ★핵심
- 경영 대시보드: CEO 5분 브리핑, RED 알림(같은 이슈 3회 반복 시 긴급 경보), 이번 주 할 일 Top 3, 우수 상담원 자동 선정 [제안 s5, s6]
- 영업기회 발굴: CRM에 적지 않은 견적 문의도 STT 원문에서 찾아냄, 미결 건 경과일 추적 [제안 s7]
- 상담원 6대 역량 별점, 가중치 기반 인사고과 점수와 신뢰도 [제안 s8]
- 표본이 5건 미만이면 점수 대신 "평가 불가" 표시 [제안 s8]
- 신입 교육자료: Best·Worst 사례집(개선 스크립트), 상황별 플레이북, 롤플레잉 대본 [제안 s9]
- 모든 항목에 실제 통화 원문 근거 표시 [제안 s5, s8]
- CRM 쪽 기능: 일일 리포트, 'AI 분석' 버튼(이슈·개선점·우수사례·전일/전주 대비), 기간별 종합 리포트, PDF 다운로드 [CRM p35, p36]

### ⑤ PC 소프트폰의 실시간 기능
- 실시간 STT: 통화 연결 시 자동 시작, 발화 구분 표시 [PC폰 p12]
- 실시간 통역: 양방향 음성 번역, 60개 이상 언어 [PC폰 p13, p14]
- 관련 특허: "다국적 작업자 대상 다중 동시 통역 기반 작업 지시 전달 시스템" [회사 p5]
- ⚠ 두 기능 모두 "계정 설정에 따라 사용이 제한될 수 있음" [PC폰 p12, p14]

### ⑥ CRM·CTI 연동
- 전화 수신 시 고객 상세 화면 자동 열림, 화면에서 모바일/소프트폰 중 골라 발신 [CRM p27, p28], [제안 s3]
- 고객 한 화면에 상담·통화·문자·주문 이력 탭 [CRM p29]
- 담당자 일괄 변경 [CRM p26] → 가이드 미션5 "담당자가 바뀌어도 이전 이력 확인"과 연결

### ⑦ 보안
- 녹취 파일 AES256 암호화 [제안 s3]
- 녹취 재생·다운로드 시 5자 이상 사유 입력 필수 [모바일 s8]
- 로그인·녹취 재생 등 사용 이력 조회 [모바일 s20]
- 권한 구분: 상담원(agent) / 매니저(manager) [CRM p1]
- 접속 비밀번호 SHA256 단방향 암호화 [홈페이지 recording.php], [가이드 미션11] (제안서는 AES256만 언급했을 뿐 충돌 아님)

### ⑧ 일괄 구축·유지보수 (서비스 업체로서의 차별점)
- 회선(기업 광랜)·전화·랜공사·녹취·CRM·유지보수를 한 곳에서 [회사 p3, p6~p10]
- 녹취서버 대규모 구축 실적: 한국전력 고객센터 3,000석, IVY 김영학원 700석, 전국 초·중·고 200여 곳 [회사 p5]
