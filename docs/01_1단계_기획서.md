# 1단계 기획서 (A-04-류지몬(2))

## 프로젝트명
팩트마케터: 현장 사진으로 고객별 설득 전략을 만드는 B2B 마케팅 AI

## 한 줄 소개
제품 자료와 설치 현장 사진을 넣으면 AI가 고객 분석(STP·JTBD·USP)부터 구매 결정자별 홍보 콘텐츠까지 만들고, 모든 문장을 원문 근거로 검증하는 B2B 마케팅 자동화 도구

## 대상 사용자
마케팅 전담 인력 없이 대표·영업 담당자가 홍보를 겸하는 직원 10명 안팎의 B2B 설치형 솔루션 기업의 마케팅 담당자.
1차 사용자는 티링크(상주 인원 7명, 녹취·CRM 솔루션을 고객사 현장에 직접 설치해 공급).

## 해결하려는 문제
1. 자료가 많고 흩어져 있음: 티링크 한 곳만 해도 제안서 11장, 매뉴얼 3종(43쪽·29장·16쪽), 회사소개서 14쪽, 블로그 가이드라인, 홈페이지 설치 사진 15장
2. 현장 사진이 단자함·서버 랙·케이블 사진이라 그대로는 고객의 관심을 끌지 못함
3. 구매 결정자가 여럿인데 홍보물은 하나: 경영진(보고·위험 관리), 영업 관리자(직원별 통화·미결 관리), 전산·총무 담당(설치 공간·회선 호환)의 관심이 다름
4. 자료끼리 내용이 다름: 직접 대조해 보니 4건(전국 학교 수 "200여 개"와 "150+", 99% 녹취 성공률의 적용 범위, PC폰 녹음 가능 조건, 암호화 방식). 확인 없이 쓰면 허위·과장 광고가 됨
5. 블로그 원고마다 필수 키워드 3개와 미션 11개를 사람이 일일이 확인

## 해결 방법
원칙: AI는 읽기·분류·추론·글쓰기를 맡고, 사실 판정은 코드가, 최종 승인은 사람이 함.
1. 자료와 사진을 사실 카드로 정리: 문장마다 출처(파일·쪽)를 붙임. 사진은 AI가 설치 형태와 장비를 판독하고, 업종·가린 고객명은 홈페이지 정보에서 코드가 붙임
2. 사실 카드로 STP·ICP·JTBD·USP와 구매 결정자별 관심사를 분석. 모든 항목을 [확인된 사실] / [AI 추론] / [검증 필요] 3단계로 표시
3. 결정자별 콘텐츠 생성 → 코드가 본문의 숫자·고객사명·필수 키워드를 사실 카드와 가이드라인에 대조 → 근거 없는 내용은 [확인 필요]로 표시
4. 담당자가 승인하고, 고친 표현은 규칙으로 저장해 다음 생성부터 적용
5. 자료·사진 속 문장은 지시가 아니라 데이터로만 취급

## 주요 기능
1. 근거 기반 마케팅 분석: 자료와 사진 → 사실 카드와 자료 간 충돌 표시 → STP·ICP·JTBD·USP와 구매 결정자 3역할 분석 보고서(3단계 표시)
2. 결정자별 맞춤 콘텐츠: 같은 현장 사진 1장으로 경영진용·영업 관리자용·전산 담당자용 카드뉴스(4장)와 블로그 원고(가이드라인 구성)를 생성
3. 사실 검증과 승인: 숫자·고객명·한정어·필수 키워드·미션 11개를 코드가 검사해 점수와 [확인 필요]를 표시하고, 승인한 것만 내보냄. 일부러 틀린 수치를 넣은 원고로 검출률을 측정

이번에 만들지 않는 것: 경쟁사 비교(제공 자료에 경쟁사 정보가 없어 지어내지 않음), 광고 성과(클릭률·전환율) 분석, 블로그·SNS 자동 게시, 포스터·영상 생성

## 기술 스택
- Python (전체 처리 흐름)
- Streamlit (웹 화면: 분석 · 콘텐츠 · 검수 3개 탭)
- Claude (자료 분석, 마케팅 분석, 원고 작성)
- Gemini (현장 사진 판독, 두 번째 모델로 교차 검증)
- PyMuPDF · python-pptx · openpyxl (PDF·PPT·엑셀 텍스트 추출)
- Pillow (카드뉴스 이미지 생성)
- JSON (사실 카드·검수 규칙 저장), GitHub (코드 공개)
